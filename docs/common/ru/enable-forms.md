# Подключить {{ forms-full-name }} для бизнеса

Пользователи организаций, зарегистрированных на платформе {{ ya-360 }}, могут использовать сервис {{ forms-full-name }} в своей работе: создавать формы для проведения опросов, тестов, приема заявок и обращений от клиентов. Подробнее о возможностях {{ forms-full-name }} для бизнеса читайте в разделе [{#T}](forms-for-org.md).

Если у вас нет организации {{ ya-360 }}, вы можете ее создать. О том, как это сделать, читайте в [документации {{ ya-360 }}]({{ support-business-create-org }}).

Если у вас уже есть организация в {{ ya-360 }}, сервис {{ forms-full-name }} для бизнеса будет автоматически активирован при первом входе любого пользователя организации:

1. Перейдите на страницу [{{ link-forms-b2b }}]({{ link-forms-b2b }}).

1. [Войдите в аккаунт](login.md), который вы используете для работы в организации.

1. Если ваш аккаунт зарегистрирован в нескольких организациях, выберите организацию, в которой вы хотите использовать {{ forms-full-name }}. Затем нажмите кнопку **Продолжить**.

{% note warning %}

Если ваш аккаунт не зарегистрирован в организации {{ ya-360 }}, при первом входе в {{ forms-full-name }} будет создана [организация в {{ yandex-cloud }}]({{ docs-org }}).

Для корректного подключения {{ wiki-name }} используйте аккаунт в организации {{ ya-360 }}.

{% endnote %}

Если у вас не получается подключить {{ forms-full-name }} к организации {{ ya-360 }}, обратитесь [в службу поддержки]({{ link-forms-feedback }}).
